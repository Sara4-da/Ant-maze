Ant in a flooded maze using c++ oop
searching for the ants food X using GREEDY SEARCH,A*SREACH ,and the heuristic h1(eucliden),h2(Manhattan) for each algorithm

run the program as following:

enter the size of your maze, 
enter  F for free space that the ant can move,W for the wall(ant cant move),L for flooded cells,X for the food cell.
